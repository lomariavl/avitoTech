- **Задание 1** находится в файле "ЛобановаМВ_AvitoTech.pdf"
- **Задание 2** в каталоге task_2_2

## Необходимые шаги для запуска проекта:

### 1. Клонировать из репозитория

```
git clone https://github.com/lomariavl/avitoTech.git
```

### 2. Создать виртуальное окружение

```
python3 -m venv .venv
source .venv/bin/activate
```

для Windows

```
py -m venv .venv
.venv\Scripts\activate
```

### 3. Установить зависимости

```
pip install -r requirements.txt
```

### 4. Запустить тесты

```
PYTHONPATH=. pytest task_2_2 
```
